# 실험 지도

사용자가 2026-10-26 제공한 맵 이미지의 문·연결 통로를 `layout.json`에 기록했다. 연결은 양방향이다. 환풍구는 정상 이동 경로로 추가하지 않았다.

- 중앙홀에서 회의실·통신실·기록실·창고·전력실로 연결된다.
- 서버실은 기록실·전력실로 연결된다. 중앙홀과 직접 연결되지 않는다.
- 기록실↔전력실 이동은 현재 Action에서 서버실 경유로 작성했다. 중앙홀 경유도 맵상 가능하지만 해당 기록의 경로는 서버실 경유다.
- 그림상 기록실 서쪽이 중앙홀 출입구, 동쪽이 서버실 연결 방향이다. 방 내부의 정확한 좌표·거리·이동 속도는 아직 정하지 않았다.

## Action 시각과 경로

정상 방간 이동을 서술한 첫 시각은 **도착 시각**이다. 출발 시각이 따로 없으면 이전 위치 기록 이후 해당 도착 시각 사이에 통로를 이동한 것으로 읽는다. 방 안 행동·접촉·포획 시각은 기존 사건 발생 시각을 유지한다. 순간이동은 별도 명시한 버그 사건이다.

기존 location_ids의 출발·도착 메타데이터는 유지하고 경유 경로는 본문에 명시했다. 이 배열을 전체 경로 또는 경유지 노출 정보로 해석하지 않는다. 따라서 경유지는 본문 full 공개 시 읽을 수 있지만 해당 경유지를 location_ids 검색 조건으로 찾는 것은 현재 보장하지 않는다. 검색용 경유 메타데이터 확장은 E/F와 별도 협의한다.

경유 방에 다른 AI가 있어도 자동 목격으로 처리하지 않는다. 시선·정확한 통과 시각을 서술한 경우에만 그 장면의 지식으로 연결한다. 같은 방의 모든 벽이 같은 버그 지점이라는 뜻도 아니다.

8회차 YB-5의 회의실 도착을 100초에서 109초로 조정했다. 95초 창고 포획 후 96초 출발·103초 중앙홀 진입·109초 회의실 도착이며, YB-3은 YB-2 추격에 집중해 통과를 보지 못한다. 120초·126초 포획 및 공식 점수는 유지한다. 이는 시나리오 동선 설정이며 실제 속도 검증 결과는 아니다.

9회차 YB-4는 기록실 출입구와 YB-2의 안쪽 위치를 알고 빠른 재등장을 의심한다. 통과·도착은 직접 보지 못하고 벽 통과를 확신하지 않는다. 벽 통과는 기록실→중앙홀의 비정상 위치 변경이며, 두 방이 벽을 직접 공유한다고 가정하지 않는다.

맵은 현재 콘텐츠 작성 기준 자료다. 런타임 로더·물리 시뮬레이션에 자동 연결되지 않으며 포획 후 잔류·이동 규칙과 실제 거리·속도 검증은 후속 과제다.
