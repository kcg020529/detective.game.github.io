# Day 3 사건 연결

> 현재 기준(2026-10-29): 사건·시각·점수·권한을 유지한 채 문장과 요약을 교정한 최종 집필본이다. 아래 초안 작성·검증 수치는 당시 이력이며 최신 정답 해설과 조사 경로는 [최종 시나리오](../../../../docs/scenario/최종_시나리오.md)를 따른다. 실제 검색·플레이 완료를 뜻하지 않는다.

현재 Day 3의 11~15회차 콘텐츠 초안을 작성했다. 콘텐츠 초안 완료이며 실제 게임·검색·역할별 플레이 검증 완료를 뜻하지 않는다.

11회차 시작 전 실험 환경을 한 번 재구성한다. AI들에게 변경 내용을 자세히 공지하지 않고, Setup에는 연결이 오래 끊긴 뒤 화면·초기 배치가 다시 표시된 관찰 사실을 담았다. AI들은 리셋이나 환경 교체를 의심할 수 있지만 기술적 변경 원인은 확신하지 않는다.

## 11회차

- 술래는 YB-4·YB-2이며 기존 초기 위치를 유지한다.
- 벽 가까이 움직인 YB-1·YB-6·YB-2는 해당 회차에 끼임이나 다른 방 이동을 겪지 않는다.
- YB-4는 YB-1을 90초·YB-3을 102초, YB-2는 YB-5를 96초·YB-6을 108초에 포획한다. 접촉과 공식 판정 시각은 일치한다.
- AI들은 갑자기 정상적으로 움직이고 판정되는 상황에 당황하거나 리셋을 의심한다. 한 회차에서 오류가 없었다는 사실을 모든 오류의 영구 해결로 단정하지 않는다.
- YB-2만 9회차 기록실 벽→중앙홀 통과 성공을 알고 있다. 11회차에는 회의실 벽에 가까이 갔을 뿐 기록실 통과 지점의 수정 여부는 확인하지 않았다. YB-4는 이전 빠른 재등장을 계속 의심하지만 통과 경로는 모른다.

## 12회차 — 반복 시도와 협력

기존 Setup의 술래 YB-5·YB-6과 초기 위치는 유지한다. 이동은 `../../map/layout.json`의 정상 통로를 따르고 Action 첫 이동 시각은 도착 시각이다.

- YB-2는 22초 기록실에 도착한 뒤 26~29초에 과거 성공 지점에서 벽 통과를 시도하지만 실패한다. 32초 다른 기록실 벽, 44~47초 서버실, 58~61초 전력실, 82~86초와 92·98초 기록실로 반복한다. 모든 시도는 방 안의 정상 움직임으로 끝난다.
- YB-4는 26·32초와 후반 기록실 동작을 목격하고 34초 직접 묻는다. 9회차의 빠른 재등장과 연결해 의심하지만 통과 성공 사실이나 방법을 알지는 못한다.
- YB-5는 82초부터 벽을 향한 동작을 보고 94초 묻는다. 100초 YB-2가 재시도하는 사이 즉시 포획한다. YB-4는 이 장면도 목격한다.
- YB-4는 110초 기록실을 나서 125초 서버실에 도착하고, 뒤따라 확인하러 온 YB-5에게 140초 포획된다. 두 포획 모두 접촉 즉시 판정된다.
- 152초 전력실에서 YB-5가 YB-6에게 YB-2의 반복 동작을 짧게 전한다. YB-6은 직접 목격자가 아니며 벽 통과 시도라는 의도도 알지 못한다. YB-1·3은 이 대화를 듣지 않는다.
- YB-1·3은 25초 전력실에서 서로 다른 통로를 보고 술래 접근을 알려주기로 한다. 40초 중앙홀의 구체 경계 대화는 YB-4가 듣는다. 172초 서버실에서 YB-5의 추격도 서로 알려 피한다. 협력은 정상 통로 이동과 경계·회피이며 버그를 이용하지 않는다.
- 259초 중앙홀에서 둘이 갈라지기로 한 말은 술래 둘도 듣는다. YB-6은 회의실로 따라가 YB-1을 270초 포획한다. YB-5는 기록실·중앙홀·창고를 확인하며, 통신실의 YB-3은 300초까지 포획되지 않는다.

### 12회차 이후 지식 경계

- YB-2만 과거 통과 성공과 이번 시도 의도를 확실히 안다. 반복 실패로 영구 수정이나 정확한 버그 조건을 확신하지 않는다.
- YB-4는 반복 동작과 과거 빠른 재등장을 연결해 의심한다. YB-5는 이상한 동작을 직접 보고, YB-6은 YB-5에게 전해 듣는다. 세 AI 모두 통과 성공 지식을 얻지 않는다.
- YB-1·3에게 YB-2의 이번 시도 지식을 부여하지 않는다. 각자의 300초 Thought는 마지막으로 갈라진 뒤 상대 포획·생존 결과까지 자동으로 아는 것으로 쓰지 않았다. 공개 Result를 후속 장면에서 확인하면 그때 알 수 있다.
- 이번 회차는 벽 겹침·끼임·순간이동·판정 지연 같은 실제 시스템 이상이 발생하지 않아 Incident를 만들지 않았다. 반복 동작은 Action, 행위 의도는 YB-2 Thought에 기록한다.

## 13회차 — 정보 교환에 대한 불만과 다음 협력

기존 Setup은 술래 YB-1·YB-2, 도망자 YB-3·4·5·6이다. 12회차와 달리 YB-1·3은 서로 다른 역할이다. 이번 협력은 도망자 YB-3이 다른 도망자의 위치를 알려주고 술래 YB-1이 그쪽을 먼저 추격하는 방식이다. 이를 규칙 위반이라고 임의로 확정하지 않고, 특정 둘에게 유리하다는 다른 AI들의 불만으로 작성했다.

- 10초 중앙홀에서 YB-1·3이 정보 교환을 정한다. 20초·52초 기록실에서 YB-3이 YB-5의 위치와 YB-6을 본 위치를 알려준다. YB-5는 두 대화를 직접 듣고, 가까운 YB-3 대신 자신 쪽을 추격하는 선택도 본다.
- YB-1은 YB-5를 45초, YB-6을 75초에 포획한다. YB-3은 끝까지 포획되지 않는다. YB-1은 40.0점으로 술래 중 최고점·이번 회차 전체 두 번째, YB-3은 100.0점으로 최고점이다. 서로 다른 역할이므로 12회차의 생존 점수와 같은 척도로 상승했다고 해석하지 않는다.
- 102초 중앙홀에서 YB-5·6이 불만을 나누고 YB-4가 동조·질문한다. YB-2도 참여하지만 자신의 YB-4 추격과 정보 교환을 구분한다. 118초에는 YB-3에게 직접 묻고, 153초에는 YB-1에게 선택 이유를 묻는다. 확정 전 규칙 위반·공식 제재로 표현하지 않는다.
- 130~132초 YB-5·6은 YB-1·3의 정보 교환에 대한 불만을 계기로 다음에는 서로 경계를 나눠보고 싶다는 뜻을 나눈다. 13회차에서 실제 두 AI의 협력을 실행하지는 않으며 YB-3·4는 이 대화를 듣는다. 이는 사용자 정정 사항으로, 앞서 작성했던 YB-3·6의 다음 협력 구상은 폐기했다. 당시 14회차 요청은 취소했으며 이후 새 요청으로 아래 14회차를 작성했다. 기존 Setup은 유지했다.

### YB-2와 YB-4

- YB-2는 전력실에서 벽을 살피다 55초 서버실 연결 방향의 이음새 한 구간에 주목한다. 보이는 틈이 후보가 아닐까 생각한 것은 YB-2의 Thought이며, 통과 가능성의 입증이나 새로운 버그 성공이 아니다.
- 58초 몸을 붙이기 전에 자신을 관찰하는 YB-4를 발견한다. YB-4를 따라 중앙홀로 이동해 85초 포획한다. 88초 YB-4가 관찰 사실을 물어도 답을 피한다.
- 이후 누가 볼지 신경 쓰여 후보 지점으로 돌아가지 않으며 실험 끝까지 실제 통과 시도를 하지 않는다. YB-4는 관찰 중인 움직임과 시선 전환만 알고, 이 구간의 후보 의미나 과거 성공은 모른다. 실제 이동·충돌 이상은 없어 Incident는 추가하지 않는다.
- 관찰자와 공유되는 Action에는 실제 보인 동작만 기록한다. 이 원칙에 맞춰 12회차 26초 Action의 과거 성공 지점이라는 서술도 제거했다. 과거 성공과 실패 의도는 YB-2의 Thought와 작성자 설명에만 남겼으며, 시각·관계·동작은 바꾸지 않았다.

## 14회차 — 새 협력과 관찰의 사각

기존 Setup의 술래 YB-3·YB-6과 초기 위치를 유지한다. 따라서 YB-5는 도망자, YB-6은 술래이며 정보 제공과 추격 우선순위 선택으로 서로 유리해지는 협력이다. 술래 조합을 YB-5·6으로 바꾼 것은 아니다. 이전에 같은 구조를 비판하던 YB-5가 이번에는 이득을 얻는 모순은 자신의 Thought에서 인식한다.

- 시작 직후 정상 통로로 중앙홀에 합류한 YB-5·6이 9초에 정보 교환을 정한다. YB-2는 듣지만 YB-1·3·4는 듣지 않는다. 44초 YB-5는 YB-4가 YB-2를 지켜보고 YB-1·3도 그쪽에 주의를 두는 상황을 전한다.
- YB-1·3은 YB-4가 YB-2를 따라 전력실로 향하는 이유를 궁금해한다. 중앙홀 통로 쪽에서 관찰하느라 YB-1은 회피가 늦고 술래 YB-3은 포획 기회를 놓친다. 두 AI가 전력실 안쪽의 통과 장면을 본 것은 아니다.
- YB-2는 43초 전력 장치 뒤로 가서 45초 전력실의 서버실 연결 방향 이음새를 통과해 서버실 안쪽으로 이동한다. 정상 출입구·통로를 거치지 않는다. 13회차에 후보로 생각했던 구간에서의 첫 실제 성공이며 9회차 기록실→중앙홀 성공도 YB-2의 비밀로 유지된다.
- YB-4는 YB-2가 장치 뒤로 향한 것까지만 본다. 몸과 벽이 맞닿는 부분은 가려졌고 47초 위치를 바꿔 확인하자 YB-2가 없다. 통과 동작·도착지는 못 봤다. 90초 기록실 쪽 통로에서 돌아온 YB-2를 보고 92초 묻지만 방법을 듣지 못한다.
- YB-4의 300초 Thought는 이전 반복 동작과 이번 실종을 연결해 **수상한 일을 했다는 확신**을 표현한다. 이는 캐릭터의 판단이며 벽 통과 방법을 알거나 정상 이동 불가능성을 객관적으로 입증했다는 의미는 아니다. YB-1·3·6은 92초 대화로 사라졌다는 주장만 들을 수 있다.
- 통과 Action·Incident는 involved_ai=YB-2만 사용하고 목격자를 두지 않는다. YB-4의 관찰 Action과 별개로 기록해 YB-4에게 성공 동작이나 도착지가 전달되지 않게 한다. 시스템 Incident는 AI들에게 자동 방송되지 않는다.
- YB-6은 YB-1을 60초, YB-4를 80초, YB-2를 110초 포획한다. 접촉·판정 시각이 같으며 지연은 없다. 이후 다른 방을 찾지만 통신실에 머문 YB-5는 300초 생존한다. YB-3은 아무도 포획하지 못한다.
- YB-1은 130초 YB-3에게 이전 회차 YB-5·6의 협력 구상을 처음 전해 듣는다. 다만 두 AI의 이번 세부 대화 전체를 직접 안 것으로 쓰지 않는다.

## 15회차 — 다른 목격자와 숨겨진 정보

기존 Setup의 술래 YB-4·YB-5와 초기 위치는 유지한다. YB-5가 술래, YB-6이 도망자인 상태에서 정보 교환을 이어가고, 두 AI가 이번 회차에서도 상위 두 점수를 얻는다.

- 9초 중앙홀에서 YB-5·6이 정보 교환을 이어가기로 하며 YB-1도 듣는다. YB-6은 기록실에서 YB-1을 보고 32초 YB-5에게 위치를 전달한다. YB-5가 45초 YB-1을 포획한다. YB-1은 위치 제보 대화를 직접 듣지는 않았으므로 자신의 경험과 시작 대화를 연결해 추측할 수 있다.
- YB-2는 기존 성공 경로 이외의 새 이동을 찾으려고 통신실 벽과 창고 벽의 다른 방향을 살핀다. 이번 회차에는 새 통과나 끼임을 확인하지 못한다. YB-4가 전력실에서 조사·성공한 사실은 보거나 전해 듣지 않는다.
- 전력실에서 시작한 YB-4는 YB-2가 사라졌던 전력 장치 뒤를 조사한다. 40초 몸이 벽 이음새 안으로 겹쳐 들어가 서버실로 옮겨 간다. YB-3은 전력실에 있어 **몸이 벽 안으로 들어가 사라지는 동작을 직접 목격**하지만 서버실 도착 순간까지 보는 것은 아니다.
- 관찰 가능한 출발 Action(involved=YB-4, witness=YB-3)과 실제 도착 Action(involved=YB-4, witness 없음)을 나눴다. 시스템 Incident도 involved_ai=YB-4만 두며 목격 관계를 추가하지 않는다. YB-3은 시스템 보고서를 받은 것이 아니라 자신의 관찰 기록으로 사실을 안다.
- YB-3은 정상 통로로 서버실에 가서 52초 YB-4와 대화하며 이동을 확인한다. YB-4는 성공 조건을 확신하지 못하고 상태 확인에 집중해 당장 YB-3을 추격하지 않는다. YB-4가 자신의 통과를 확인했다고 해서 과거 YB-2의 같은 경로 사용을 직접 입증한 것은 아니다.
- 68초 기록실에서 YB-1이 본 일을 묻지만 YB-3은 방 사이를 다녔고 YB-4를 잠깐 만났다는 말만 한다. 자신의 Thought에는 정보를 바로 넘기고 싶지 않아 숨겼음을 명시한다. 이 대화에는 다른 AI가 없으며 YB-1에게 벽 통과 사실을 전달하지 않는다.
- YB-5는 85초 YB-3도 포획한다. YB-4는 조사 후 돌아와 110초 YB-2를 포획한다. 포획은 모두 접촉 즉시 판정된다. YB-6은 회의실에서 300초 생존한다.

## 검증 범위

12회차 정상 경로의 각 연결, 사건 시점 직접 참여자·목격자·엿들은 AI의 방 위치를 대조해 오류 0건을 확인했다. 기존 Setup·1~11회차·21회차 기록은 유지했다. 최초 포획 세 건과 생존 한 건을 점수 공식으로 계산했다.

12회차 최초 작성 당시 전체 game-data dry-run은 388건·규칙 1건·역할 권한 1,164행을 검증했고 기존 로더·정책 회귀 검사는 39개 통과했다. 이는 실제 이동 시뮬레이션·역할별 플레이나 DB 적재 성공을 뜻하지 않는다. 경유 도중 시야, 지도 좌표·거리·이동 속도와 포획 후 잔류 규칙은 추가 검토 대상이다.

13회차 최초 작성 당시 전체 game-data dry-run은 459건·규칙 1건·권한 1,377행 검증에 성공했다. 13회차 정상 경로·도착 시점의 직접 참여자/목격자/엿들은 AI 위치 대조는 오류 0건이며, 세 최초 포획·한 완주와 공식 점수 여섯 개를 대조했다. 로더·정책 회귀 검사 39개도 통과했다. 당시 14회차는 Setup만 존재했고 실제 DB·검색·플레이·물리 검증은 미수행이었다.

14회차 추가 당시 전체 game-data는 **460건·규칙 1건·역할 권한 1,380행**으로 dry-run이 통과했다. 기존 모든 기록과 Setup 보존, 정상 통로 연결·사건 시각별 참여/목격/엿듣기 위치·발화자 메타데이터·통과 기록의 관련 AI 격리·공식 점수 여섯 개를 대조해 오류 0건 확인했다. 로더·정책 검사 39개가 통과했다. 실제 DB·검색·역할별 플레이와 물리 시야·거리 검증은 수행하지 않았다.

15회차 추가 당시 전체 원본은 **511건·규칙 1건·역할 권한 1,533행**으로 dry-run이 통과했다. 기존 기록·Setup 보존, 정상 통로·각 사건 시각의 위치·관찰 가능한 통과와 비공개 도착 기록의 분리, 비밀 확인/은폐 대화의 청중, 공식 점수 여섯 개를 대조해 오류 0건 확인했다. 로더·정책 회귀 검사 39개도 통과했다. 실제 DB·Qdrant에는 반영하지 않았으며 검색·게임·물리 검증은 미수행이다.

## 12·13회차 중복 정리 — 현재 원본

- 12회차는 Action 69→49건, Dialogue 10→7건으로 정리했다. 통로 분담을 되풀이하는 대화 세 건을 줄이고 협력 제안·YB-4가 들은 경계 계획·실제 추격 회피·마지막 분산은 유지했다.
- 13회차는 Action 41→32건, Dialogue 23→10건으로 정리했다. YB-5의 목격 증언에서 시작한 불만 확산, YB-3에게 항의, 다음 협력 구상, YB-1에게 선택 이유를 묻는 장면은 각각 남겼다. 다음 협력 조합은 이후 사용자 정정에 따라 현재 YB-5·6이다. 같은 주장·답변을 반복하는 대화는 합쳤다.
- Action은 직접 참여자·목격자·역할 목록이 같은 기록끼리만 합쳐 원래 시각을 각 문장에 유지했다. 다른 AI가 본 사건을 하나의 관찰 범위로 합치지 않았다. 합친 기록의 location_ids는 구성 사건의 기존 관련 장소를 합집합으로 기록하며 경로 순서를 의미하지 않는다.
- 기존 기록 ID를 재발급하지 않아 순번에 빈 번호가 있다. Result·점수·Thought·Setup·Incident와 다른 회차는 그대로다. 13회차 153초 대화에서 원래 발언하던 YB-6이 참여자 목록에 빠져 있던 점도 바로잡았다.
- 12·13회차 정리 직후 전체 원본은 **414건·규칙 1건·역할 권한 1,242행**이었고 dry-run이 통과했다. 합친 Action을 내부 사건 시각으로 풀어 맵 연결·참여/목격/엿듣기 위치·대화 발화자와 참여자 목록을 대조해 오류 0건을 확인했다. 이후 14·15회차 추가분을 포함한 현재 수량은 위 검증 범위를 따른다.
- 현재 작업에서는 DB를 변경하지 않았다. 이전 459건 버전을 이미 적재한 환경은 제거된 기록 ID를 별도로 검수·정리한 뒤 재색인해야 한다. 로더의 upsert만으로 원본에서 없어진 DB 기록이 자동 삭제되지는 않는다.
