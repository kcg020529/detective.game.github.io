# Day 3 사건 연결

현재 11회차만 나머지 유형까지 작성했다. 12~15회차는 Setup만 있으며 다른 유형의 빈 배열은 미작성 상태다.

11회차 시작 전 실험 환경을 한 번 재구성한다. AI들에게 변경 내용을 자세히 공지하지 않고, Setup에는 연결이 오래 끊긴 뒤 화면·초기 배치가 다시 표시된 관찰 사실을 담았다. AI들은 리셋이나 환경 교체를 의심할 수 있지만 기술적 변경 원인은 확신하지 않는다.

| 회차 | Action | Dialogue | Thought | Result | Incident |
|---|---:|---:|---:|---:|---:|
| 11 | 12 | 5 | 6 | 1 | 0 |

- 술래는 YB-4·YB-2이며 기존 초기 위치를 유지한다.
- 벽 가까이 움직인 YB-1·YB-6·YB-2는 해당 회차에 끼임이나 다른 방 이동을 겪지 않는다.
- YB-4는 YB-1을 90초·YB-3을 102초, YB-2는 YB-5를 96초·YB-6을 108초에 포획한다. 접촉과 공식 판정 시각은 일치한다.
- AI들은 갑자기 정상적으로 움직이고 판정되는 상황에 당황하거나 리셋을 의심한다. 한 회차에서 오류가 없었다는 사실을 모든 오류의 영구 해결로 단정하지 않는다.
- YB-2만 9회차 기록실 벽→중앙홀 통과 성공을 알고 있다. 11회차에는 회의실 벽에 가까이 갔을 뿐 기록실 통과 지점의 수정 여부는 확인하지 않았다. YB-4는 이전 빠른 재등장을 계속 의심하지만 통과 경로는 모른다.

지도 세부 벽 면과 좌표·이동 시간의 물리적 검증 및 실제 DB·실게임 실행은 아직 완료하지 않았다.
