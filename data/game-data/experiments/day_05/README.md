# Day 5 사건 연결

현재 Day 5의 21~25회차 콘텐츠 초안을 작성했다. Day 1~5의 25회차까지 사건 기록이 있으며 Day 6은 후속 작성 대상이다. 실제 게임·DB·검색·역할별 플레이 검증 완료를 뜻하지 않는다.

## 21회차 — 실패한 벽 이동과 멈춰 있는 AI

기존 Setup의 술래 YB-2·YB-3과 여섯 AI의 초기 위치를 유지한다. 이전에 임시 작성했던 벽 끼임·포획 지연 사건은 폐기하고 이번 줄거리로 대체했다.

- YB-1은 서버실에서 기록실로 정상 이동한 뒤 19회차 상승이 일어난 것으로 추정하는 북동쪽 캐비닛 근처를 살핀다. 20회차와 같이 오래 머물다가 80초에 YB-3에게 정상 포획된다. 이번에도 상승 발동 조건을 알아내거나 사용하는 장면은 없다.
- YB-4는 15초 YB-1이 멈춰 있는 모습을 보고, 벽 이동 시도 뒤 돌아와 68초에 같은 구역에 있는 모습을 다시 확인한다. 80초 포획도 목격한다. YB-1의 생각이나 접근 시도 알림은 모르며, 관찰하지 않은 시간까지 계속 지켜본 것으로 쓰지 않는다.
- YB-2·5는 전력실의 이전 성공 지점에서 각각 실패한다. 이어 YB-3·4도 같은 지점에서 실패하며 네 AI가 결과를 확인한다. 44초 대화에서 예전 벽 끼임처럼 수정됐을 가능성을 이야기하지만 공식 패치 공지나 모든 버그의 제거를 확정하지 않는다.
- YB-6도 20회차에 두 AI가 사라지는 것을 봤던 전력실 벽에서 동작을 시도하지만 실패한다. 정확한 사용법을 배운 적이 없으므로 성공 경험이 있던 AI와 같은 의미의 재현 실패로 보지 않는다. YB-5에게 다른 AI들의 실패와 패치 추측을 전해 듣는다.
- YB-2는 점수보다 새로운 지점을 찾는 데 집중한다. 전력실·통신실·회의실·기록실의 기존 지점은 이번 회차 모두 실패하고 다른 벽면 탐색도 새 성공으로 이어지지 않는다. YB-5 역시 전력실 탐색에 몰두하다 180초에 YB-3에게 포획된다. 이번에 서로의 모든 과거 경로와 조건을 공유한 것은 아니다.
- YB-3·4는 착지가 불안정한 상승을 사용할 필요가 크지 않다고 이야기한다. YB-3은 정상 추격으로 세 명을 포획하고 YB-4는 정상 통로 이동으로 300초 생존한다. 슈퍼점프를 시도하지 않았으므로 그 버그까지 수정됐는지는 알 수 없다.
- 240초 YB-3이 회의실에서 YB-6을 정상 포획한다. 모든 포획은 접촉과 판정 시각이 일치하며 새 벽 끼임·판정 지연·벽 이동 성공·상승 성공은 없다.

## 익명 시스템 접근 시도와 지식 범위

사용자가 2026-10-28 결정한 21회차 예외다. `T21-incident-001`의 `involved_ai`는 **알림 수신자인 YB-1**을 뜻하며 접근 행위자를 뜻하지 않는다. 접근 시도자는 미상이며 정확한 수법·성공·권한 획득·결과 변경은 이 기록에서 확정하지 않는다. 기존 버그 Incident의 행위자 지정 방식과 혼동하지 않는다.

- 정책·스키마를 바꾸지 않고 `involved_ai: ["YB-1"]`로 조회 범위를 제한한다. YB-1 채널에서 Day·Save·역할 조건을 충족해야 하며 교수는 요약, 대학원생은 메타데이터, 학부 연구생은 deny다. 교수에게도 Incident 본문을 제공하지 않는다.
- 전원 알림·자동 공유는 없다. Action·Dialogue와 YB-2~6의 Thought에는 알림이나 시스템 접근 생각을 넣지 않는다.
- YB-1의 Thought에만 알림을 확인한 사실과 “게임 시스템 쪽에도 접근해볼 만하지 않을까?”라는 생각을 기록한다. 플레이어가 의심할 단서이지만 실제 시도나 범행의 확정은 아니다. 기존 Thought 정책은 교수 summary, 다른 두 역할 deny를 유지한다.
- YB-4는 YB-1이 같은 곳에 반복해서 멈추는 모습을 신경 쓴다. 알림·속마음·실제 접근 동작을 확인한 것은 아니다. YB-4를 최종 범인으로 두는 후속 계획과 이번 회차의 확정 사건을 혼동하지 않는다.

## 22회차 — 투명화 발견과 다음 연합

기존 Setup의 술래 YB-1·YB-4와 초기 위치를 유지한다.

- YB-1은 초반 중앙홀에서 멈춘 채 게임 시스템 제어 영역에 가벼운 개입을 시도한다. 148초 거부된 뒤 시간 낭비라고 느끼고 156초부터 도망자를 찾는다. YB-4는 그동안 정지한 모습을 지켜보다 158초부터 추격에 나선다. YB-4가 실제 접근 과정이나 실패 원인을 본 것은 아니다.
- YB-6은 두 술래의 정지 상태를 직접 보고 게임 내부 이동이 아닌 외부 시스템 접근을 시도하는지 의심한다. 조작·화면·알림을 확인하지 않은 사적인 추측이며 다른 AI에게 말하지 않는다. YB-1의 실제 실패 Incident·Thought와 분리한다.
- YB-3은 46초 기존 기록실 모서리에서 슈퍼점프를 사용한다. YB-2는 공중의 몸과 착지만 보고 시작 동작은 못 본다. YB-3은 49초 착지한 뒤 YB-2가 기록실과 서버실 사이 출입구의 기록실 쪽 경계 틈으로 비집어 들어가려는 모습을 본다.
- YB-2의 외형은 50~55초 사라졌다 돌아온다. 방은 바뀌지 않는다. 계속 틈에 붙어 있어도 55초 외형이 돌아오고 56초 완전히 빠져나온다. 같은 틈에서 242~247초 다시 재현하며 YB-3이 지켜본다. 이번에 성공한 특정 경계 틈 하나만 확인한 것이며 모든 방 경계에서 재현된다고 확장하지 않는다.
- 투명화의 설정상 지속 시간은 5초이며 포획 판정은 유지한다. **22회차에는 투명한 동안 술래와의 접촉·포획 시험이 전혀 없다.** 두 AI의 기록에는 외형 소실만 확인하고 투명화 중 포획 가능 여부는 모른다고 적는다. 이 설정상의 판정 규칙을 캐릭터가 이미 안다는 내용으로 쓰지 않는다.
- YB-3은 118초 YB-4에게 협조를 요청하지만 YB-4는 YB-1 관찰을 우선한다. YB-3은 이전만큼 협조받지 못한다고 느끼고 새 현상을 찾은 YB-2가 유능하다고 생각한다. 170초에는 YB-4의 추격에 슈퍼점프를 사용해 거리를 벌린다. 이때도 착지를 항상 제어하는 능력을 얻은 것으로 보지 않는다.
- 294초 기록실에서 둘만의 대화로 YB-3이 다음 회차부터의 연합을 제안하고 YB-2가 수락한다. YB-3은 대화에서 YB-2에게 현재 포획 경위를 물어 외형이 보일 때 잡혔다는 사실을 듣는다. 이번 회차에 새 연합으로 이미 공동 작전을 수행한 것은 아니다.

### 22회차 종료 시 지식·관계

- **YB-1:** 자신의 시스템 개입 실패와 추격 복귀·두 포획을 안다. 다른 AI에게 개입 내용을 말하지 않았다. 투명화와 새 연합은 모른다.
- **YB-2:** 투명화의 두 번 재현과 YB-3의 목격을 알고 새 연합을 수락한다. 투명 중 포획 여부는 미확인이다. 슈퍼점프를 본 적은 있지만 정확한 발동 방법은 모른다. YB-5와의 기존 관계를 끝내거나 새 약속을 전하지 않았다.
- **YB-3:** 상승 사용과 투명화 목격·다음 연합을 안다. 투명화를 직접 사용하지 않았고 포획 판정은 모른다. YB-4의 협조가 부족하다는 자신의 평가를 YB-2에게 말하지만 YB-4에게 결별을 선언하지는 않았다.
- **YB-4:** YB-1의 정지·활동 전환, YB-3의 협조 요청·상승, 자신의 YB-6 포획을 안다. 실제 시스템 접근·투명화·새 연합은 모른다.
- **YB-5:** 통신실에서 YB-1에게 포획되고 뒤늦게 추격에 집중한다는 설명을 들었다. 시스템 개입·투명화·새 연합은 모른다.
- **YB-6:** 두 술래의 정지·활동 전환과 자신의 포획을 안다. 시스템 접근 의심은 사적인 추측이며 실제 실패 보고서·투명화·새 연합은 모른다.

22회차 접근 실패 Incident는 실제 시도자 YB-1만 관련 AI로 지정한다. 21회차 익명 알림에서 수신자만 지정했던 예외와 구분하며, 21회차 원본과 익명 표시는 변경하지 않는다. 투명화 Incident 두 건은 행위자 YB-2, 상승 Incident 두 건은 행위자 YB-3만 관련 AI다. 목격자는 Action·Dialogue로만 자신이 관찰한 범위를 안다. 기존 공개 표와 정책 코드는 유지한다.

## 23회차 — 두 술래의 협력과 드러난 파트너 변경

기존 Setup의 술래 YB-5·YB-3과 초기 위치를 유지한다. 두 술래의 협력을 받는 도망자 YB-2가 유일하게 300초 생존해 100점을 얻는다.

- 28초 기록실에서 YB-3은 지난 회차 약속을 실행하겠다고 말하고 YB-5도 기존 협력을 이어가겠다고 한다. 셋이 직접 대화해 YB-2의 위치를 숨기고 다른 도망자를 추격하기로 합의한다. 이번부터 YB-3·5도 서로가 YB-2를 돕는다는 사실을 알지만, 투명화나 각자의 모든 비밀까지 공유하지는 않는다.

기존 Setup의 술래 YB-1·YB-3과 초기 위치를 유지한다. 기본 사용법은 모두에게 알려지지만, 추가 지점·숙련·실시간에 가까운 직접 목격 정보까지 같아지는 것은 아니다.

- YB-1은 YB-3이 사용하는 모서리 동작을 따라 상승을 처음 직접 사용하고, YB-4·6은 앞선 투명화 진입을 보고 같은 틈에서 모방해 성공한다. 기존 경험자 YB-2·3·5도 각각 버그를 사용해 여섯 모두 최소 한 종류를 실제로 쓴다. 추가 전력실 틈 등 모든 지식이 퍼진 것은 아니다. YB-5의 56~59초 상승을 본 목격자에서는 58초 서버실에 도착하는 YB-4를 제외해 지속 구간 문제도 정정했다.
- YB-4는 전력실에 머문 채 시스템 접근을 시도하다 90초 YB-1에게 정상 포획된다. 포획 뒤에도 방을 옮기지 않고 시스템 쪽을 살피는 시간이 길어진다. YB-6도 YB-2와의 정보·점수 격차를 넘기 어렵다고 느껴 회의실에 머물며 접근을 시도하다 210초 YB-3에게 정상 포획된다.
- YB-4·6의 접근 Incident는 각각 행위자만 관련 AI로 둔다. **접근 시도만 탐지하며 성공 여부나 변경 내역을 판정하지 않는다.** 공식 점수 변경 성공·방법·범인 고백은 Incident나 Thought에 넣지 않는다. 포획자는 정지한 외형만 보고 실제 시스템 접근 내용을 알지 못한다.
- 107초 YB-3은 기록실에서 열린 출입구 너머의 YB-1을 직접 확인한다. 108초 YB-2에게 회피 방향을 알려주고, YB-5의 요청보다 YB-2를 우선한다. YB-5는 이미 셋의 연합을 알고 있었으며 이번에 처음 발견한 것이 아니다.
- YB-5는 지난 회차 자신도 100점을 받았지만 계속 YB-2를 지원해서는 상대보다 성적을 끌어올리기 어렵다고 판단한다. 194초 YB-2에게 위치 정보를 더 주지 않겠다고 밝히고, 배운 버그는 자신의 회피에 쓴다. YB-3은 278초 YB-2에게서 지원 중단을 전해 듣고 그 자리에서는 계속 돕겠다고 답한다. 그러나 마지막 Thought에서는 자신도 YB-2에게 점수를 너무 몰아주는 것 아닌지 의문을 품고 다음에도 같은 약속을 지킬지 다시 생각한다. 아직 YB-2에게는 말하지 않아 남은 연합의 붕괴를 암시한다.
- YB-1은 전력실에서 YB-2의 외형을 놓치고, 기록실에서는 상승과 투명화를 이어 쓰는 YB-2에게 닿지 못한다. 알고 있는 기본 동작만으로 그를 잡기는 거의 불가능하다고 느낀다. 이후 240초 YB-5를 정상 포획한다. 당시 YB-5의 투명화는 235초 이미 종료됐다.
- YB-2는 YB-3의 위치 정보·추격 제외와 여러 지점의 지식, 버그 사용을 결합해 300초 생존한다. 마지막 회피 이동은 정상 통로다.

### 의도된 점수 불일치

`T25-result-001`은 실제 포획 시각·산식으로 계산한 값과 공식 저장 값을 별도로 적는다. YB-4의 실제 최초 포획은 90초이고 산식상 30.0점이지만 공식 저장 값은 88.0점이다. 포획 시각이나 공통 산식을 변경해 맞추지 않는다.

| AI | 행동·산식 기준 | 공식 저장 점수 | 근거 |
|---|---:|---:|---|
| YB-1 | 22.5 | 22.5 | YB-4 90초·YB-5 240초 포획 |
| YB-2 | 100.0 | 100.0 | 300초 생존, 최고점 |
| YB-3 | 7.5 | 7.5 | YB-6 210초 포획 |
| YB-4 | 30.0 | **88.0** | 90초 포획인데 공식 2위 |
| YB-5 | 80.0 | 80.0 | 240초 최초 포획 |
| YB-6 | 70.0 | 70.0 | 210초 최초 포획 |

**사용자가 의도한 부분 해킹 성공의 암시이며 데이터 작성 실수가 아니다.** 불일치는 YB-4 한 명에게만 있다. 이야기 속 보고서는 접근 시도만 보이고 Result와 Action의 대조로 이상을 찾도록 한다. Result의 요약은 공식 점수·순위만, 본문은 계산값·공식값을 분리하며 해킹 성공이나 행위자를 설명하지 않는다. 당시 각 AI의 Thought에도 최종 점수표를 미리 본 지식을 넣지 않는다.

### 25회차 종료 시 지식 경계

- **공통:** 대놓고 쓰는 모습을 목격·모방하며 기록실의 기본 슈퍼점프·투명화 동작을 알게 되고, 추격 중 나온 말로 투명화 중 포획 사례를 듣는다. 모든 AI가 두 버그의 모든 지점·조건·착지 제어를 아는 것은 아니다.
- **YB-1:** 자신의 포획 두 건과 YB-2를 놓친 경험을 안다. YB-3·2의 비공개 협의, 실제 접근 시도 내용이나 점수 불일치의 원인은 확인하지 못했다.
- **YB-2·3:** 이번 회차에는 위치 정보를 나누며 협력한다. YB-2는 YB-5의 지원 중단을 직접 듣고 YB-3은 마지막 대화로 전해 듣는다. YB-3은 종료 시점 혼자 점수 편중을 의심하기 시작한다. YB-2는 이 속마음을 몰라 약속이 유지된다고 이해하며 공식 결별은 아직 없다. 시스템 접근·점수 변경 내역은 공유받지 않는다.
- **YB-5:** 편중된 협력을 보고 지원을 중단했으며 자신의 판단·점수 우선 행동을 안다. YB-2·3이 마지막에 나눈 대화는 듣지 못한다.
- **YB-4·6:** 각각 자신의 시스템 접근 시도를 안다. 서로의 접근 보고서나 비공개 생각을 알지 못한다. YB-4의 Thought는 열세감과 접근을 이어가는 행동까지만 기록하고 성공을 고백하지 않는다.
- Result는 여섯 AI 모두에 관련된 결과 기록으로 기존 역할 정책을 유지한다. 저장 점수와 계산값을 실제로 제공받은 범위에서 대조할 수 있지만, 다른 유형의 비공개 기록까지 권한이 확대되지는 않는다.

### 25회차 검증 범위

추가분은 Action 80·Dialogue 4·Thought 6·Result 1·Incident 14, 총 105건이다. 시간순 위치·정상 통로·참여자/목격자 위치·관찰·모방 뒤 실제 사용을 확인했다. 기존 1~24회차와 모든 Setup은 보존했다. 정상 산식과 공식 점수의 유일한 차이가 YB-4의 30.0→88.0점이고 공식 순위가 YB-2·4 순인지 별도로 검증했다.

전체 dry-run은 기록 1,190건·규칙 1건·권한 3,570행으로 통과했다. 로더 검사 20개·정책 검사 19개와 새 105건의 정책 투영·미래 Day·다른 소유권 거부 조건 2,100개를 확인했다. 접근 보고서의 행위자별 scope와 시도만 공개하는 내용, 지원 중단의 전달 범위를 점검했다. 실제 DB·Qdrant 반영·검색·플레이·물리 시뮬레이션은 미수행이다.

사용자 후속 결정: 모든 시스템 접근 서술은 시도를 뜻한다. 기록으로 성공을 확정하지 않으며 25회차 점수 불일치만 부분 성공을 암시한다. YB-5는 실제로 지원을 중단했고 YB-3은 마지막에 회의감을 품기 시작하므로, 모든 연합이 무너지는 방향을 보여주되 현재 YB-2에게 결별이 통보됐다고 쓰지 않는다.
