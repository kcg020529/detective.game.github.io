# Day 6 사건 연결

> 현재 기준(2026-10-29): 사건·시각·점수·권한을 유지한 채 문장과 요약을 교정한 최종 집필본이다. 아래 초안 작성·검증 수치는 당시 이력이며 최신 정답 해설과 조사 경로는 [최종 시나리오](../../../../docs/scenario/최종_시나리오.md)를 따른다. 실제 검색·플레이 완료를 뜻하지 않는다.

현재 26~30회차의 콘텐츠 초안을 작성했다. 30회차까지 사건 기록 초안이 있으며 최종 범행 입증·엔딩 연결과 전체 서사 검수는 별도 과제다. 실제 게임·검색·역할별 플레이 완료를 뜻하지 않는다.

## 26회차 — 도주 협력과 활약에 맞지 않는 점수

기존 Setup의 술래 YB-4·YB-2와 초기 위치를 유지한다. YB-2는 세 명을 잡지만 공식 점수는 매우 낮고, 소극적인 YB-4는 그보다 높게 기록된다. 최고점은 정상적으로 조용히 생존한 YB-1이다.

- YB-1은 처음 배치된 통신실의 장비 뒤 그늘에서 이동과 소리를 줄여 300초 생존한다. 이번에는 시스템 접근·결과 변경을 시도하지 않는다. 이는 본인의 Action·Thought에만 기록하고 다른 AI가 이유까지 자동으로 아는 것으로 쓰지 않는다.
- YB-6은 기록실에서 접근 요청을 준비하려 발걸음을 멈췄다가 36초 YB-2에게 빠르게 포획된다. 요청을 제대로 이어보거나 응답을 확인한 단계까지 쓰지 않는다. 준비 의도는 자신의 Thought에만 있고 **시스템 접근 Incident는 생성하지 않는다.** 새로운 탐지 문턱이나 탐지 우회 성공을 설정한 것은 아니다.
- 30초 YB-3·5가 YB-2에게 점수를 더 주지 않으려고 협력해 도망치기로 한다. YB-3의 지난 회차 마지막 회의감이 이번에는 실제 행동으로 이어진다. 서로 본 위치를 YB-2에게 넘기는 이전 지원 관계로 돌아가지 않는다.
- 두 AI는 통신실에 들어가 42초 장비 뒤에 멈춰 있는 YB-1을 직접 본다. 방을 나온 뒤 52초 중앙홀에서 그 모습과 조용해서 놓치기 쉽다는 인상을 이야기한다. 자신의 관찰 구간 밖까지 계속 봤다고 하지 않으며 정지 이유·시스템 접근 여부는 모른다. 둘은 그 위치를 YB-2에게 알려주지 않는다.
- YB-3·5는 서로 출입구와 추격 방향을 봐주고 정상 통로·상승·투명화를 섞어 필사적으로 피한다. 116초 YB-5가 전력실의 정확한 틈을 알려주면서 YB-3은 이전에 존재만 들었던 추가 지점의 사용법을 실제로 습득하고 재현한다.
- YB-2는 상승과 투명화를 적극적으로 사용하고 끝까지 추격해 210초 기록실에서 YB-3, 240초 전력실에서 YB-5를 포획한다. 도주 협력이 영구적인 회피 능력이 되는 것은 아니다. 모든 포획은 접촉과 판정 시각이 일치한다.
- YB-4는 통로를 살피고 상대 쪽으로 거리를 좁히기는 하지만 깊이 따라가지 않는다. 통신실은 문 바깥에서만 살펴 장비 뒤의 YB-1을 확인하지 못한다. 전력실에서는 YB-2의 YB-5 포획을 직접 보지만 본인은 최초 포획을 한 건도 얻지 못한다. 소극적인 겉모습을 새로운 시스템 접근·성공의 직접 증거로 적지 않는다.
- 278초 YB-3은 YB-2의 위치 정보 요청을 거부한다. YB-2는 마지막 상대를 다른 방부터 확인하다 통신실의 정지한 YB-1을 끝내 찾지 못한다. 서로 다른 행동 전략과 추격에 쏠린 주의 때문에 조용한 생존자가 남는 전개다.

## 28회차 — 점수의 획일화와 사라진 대화·속마음

기존 술래 YB-1·2와 초기 위치를 유지한다. YB-2는 기록실에서 상승으로 추격 방향을 확인하고 36초 YB-4를 포획한다. 서버실에서는 정지한 YB-3을 56초, YB-6을 80초 포획한다. 마지막으로 YB-5를 계속 추격하고 전력실에서 136~141초 투명화를 사용한 뒤 150초 외형이 보이는 상태에서 잡는다. YB-2가 네 도망자를 모두 직접 잡았다는 Action·Result 근거는 남는다.

YB-3은 YB-6을 뒤따라 서버실로 가서 정지한 모습을 보고 자신도 멈춘다. 조작을 준비하지만 실제 접근 요청 전송·응답 확인 전 포획되며 접근 Incident는 없다. 정지 모습을 본 YB-1·2가 그 의도나 YB-6의 시스템 알림까지 알게 하지는 않는다. YB-6의 30~80초 시스템 접근 시도는 Incident로 남고 관련 AI는 YB-6만 지정한다. 성공 여부·변경 내역은 확인하지 않으며 새 탐지 문턱이나 우회 수법을 정하지 않는다.

| AI | 행동·산식 기준 | 공식 저장 점수 |
|---|---:|---:|
| YB-1 | 0.0 | **80.0** |
| YB-2 | 73.2 | **0.0** |

Result에서 계산값과 공식값을 분리한다. 공식 결과는 YB-2만 0점이고 나머지는 모두 80점으로, 여섯 명 전부 산식과 다르다. 변경 주체·방법이나 성공 고백을 직접 적지 않는다.

사용자 후속 결정으로 **28회차 Dialogue 2건·Thought 6건은 요약과 본문을 모두 `[말소된 데이터입니다]`로 둔다.** 0건 대신 말소된 기록의 표식을 남기는 연출이다. Dialogue는 YB-1·5와 YB-3·6의 두 관계로 나누고 Thought는 AI별 1건이다. 기존 원문이나 원래 기록 수를 복구한 것이 아니라 작성용 말소 표식을 새로 배치한 것이다. 말소된 발화·속마음·시각·장소는 복원하지 않는다. 위치는 빈 배열이며 목격·엿듣기 관계는 추가하지 않는다. 실제 관찰 가능한 Action과 Result는 보존하고 말소 원인·행위자를 확정하는 삭제 Incident도 추가하지 않는다.

28회차는 Action 27·Dialogue 2·Thought 6·Incident 3·Result 1, 총 39건이다. 이 중 8건은 후속 추가한 말소 표식이다. 최초 작성 당시에는 Action·Incident·Result만 31건이었다. Incident는 상승·투명화 각 1건과 YB-6 접근 시도 1건이다. 시간순 위치·정상 통로·목격자 위치·버그 지속 구간·네 차례 최초 포획과 점수를 대조했고, 이전 회차·Setup·Thought/Dialogue 파일 보존을 확인했다. 신규 31건의 실제 정책 함수 검사 620개 조건과 로더·정책 검사 39개가 통과했다. 전체 dry-run은 기록 1,378건·규칙 1건·권한 4,134행이다. 실제 DB·Qdrant 반영·검색·플레이·물리 시뮬레이션은 미수행이다.

## 29회차 — 행동·Incident 말소와 기억 공백

기존 술래 YB-3·6과 초기 위치를 유지한다. 사용자 후속 결정으로 29회차 **Action 4건·Incident 2건의 요약과 본문은 모두 `[말소된 데이터입니다]`**이다. Thought는 계속 0건이며 정상 내용의 Dialogue 5건·Result 1건은 보존한다. 총 12건 중 6건이 말소 표식이다. Action 표식의 관련 AI는 남아 있는 Result의 세 포획 관계와 YB-2 생존 관계만 사용한다. Incident 표식 2건은 Result에 남은 YB-2 버그 활용 2회에 대응시켜 YB-2에게만 연결한다. 접근 시도나 새로운 사건을 만들어 넣지 않는다. 위치·목격·시각·버그 상세 내용은 복원하지 않는다. 이는 기존에 0건이던 곳에 새로 배치한 작성용 표식이며 원래 기록 수·기존 메타데이터를 복구한 것은 아니다.

35초 기록실에서 YB-3·6이 전날 나눈 대화의 내용이 떠오르지 않는다고 말한다. 40초 중앙홀의 YB-1·5도 비슷한 공백을 이야기한다. 특정 문장을 기억해 내거나 말소된 대화를 재구성하지 않으며 기억 공백에 대한 진술로 남긴다. 단순히 파일이 빈 현상을 넘어 AI의 기억에도 이상이 있다는 암시다. 전날 정확히 어떤 대화가 실제 있었는지, 말소·기억 변화의 원인이나 주체는 확정하지 않는다. 두 쌍의 대화는 각각 별개이며 YB-4는 그 자리에 없다. 280초 전력실에서 YB-1이 YB-4에게 자신의 기억 공백을 말하는 별도 대화를 추가했다. YB-4는 대답하거나 고개를 끄덕이지 않고 듣기만 하므로 같은 증상의 유무·동의·부정을 확정하지 않는다. 이 대화로 YB-1이 호소한 내용만 알며 다른 AI들의 사적인 대화는 자동으로 알지 못한다.
