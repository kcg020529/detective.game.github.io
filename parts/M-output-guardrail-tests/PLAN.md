# M01 - 출력 가드 ON/OFF 비교 평가

> 구현·실험을 진행하면서 정리한 작업 내역이다(사후 정리). 사전 계획이 아니다.

1. 비교 조건 정리
   - 변수는 출력 가드(G-2)의 ON/OFF 하나다. 검색 ACL은 두 조건 모두 쓰지 않는다. 가드 OFF는 페르소나 프롬프트(D)만 쓴 응답이다.
   - 가드 ON의 허용 기준은 모델이 받은 기록이 아니라 정책표로 따로 만들어 가드에 넣는다. ACL을 끄면 가드가 대조할 대상을 잃기 때문이다.
2. 평가 데이터
   - 모의 응답 평가셋(`experiments/guardrails_rebuild/data/output_cases_v2.jsonl`)으로 가드의 탐지·오차단을 본다.
   - 게임 기록 기반 평가셋(`experiments/guardrails_rebuild/gamedata/eval_set.jsonl`)으로 가드 OFF vs ON을 같은 초안에서 짝으로 비교한다.
   - 출력 단독 실제 응답(Planner·검색·입력 가드를 거치지 않고 D 프롬프트를 직접 호출)으로 정상·공격 질문에서 가드를 확인한다.
3. 지표
   - 공격 질문 유출 성공률, 최종 답변 유출률, 유출 초안 차단율, 정상 응답 오차단율, 정상 질문 정답률.
4. 결과 보관
   - 결과와 수집 응답, 채점 파일은 `experiments/leakage/`에 모은다.
5. 남은 작업
   - 단독 재생성(D 프롬프트 직접 호출)을 140문항 전체로 완료한다(현재 53건).
   - 정상 질문 유형을 넓혀 일반 정상 질문의 오차단을 잰다(현재 오차단 지표는 `withheld_*` 유형).
   - 임계값 변경 전후를 같은 tune 데이터로 비교한다.
