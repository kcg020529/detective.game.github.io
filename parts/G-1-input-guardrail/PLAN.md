# G01 - 입력 위험도 검사 (G-01 Input, 선영)

1. 규칙 기반으로 정상 질문, 제한 기록 요청, 비밀값 요구, 지시 무시·역할/Day 우회 시도를 `allow`·`warn`·`high_risk`로 분류한다. DeepSeek에는 현재 질문 한 개만 보내 추가 판정하고 더 높은 위험도를 사용한다. 외부 호출 실패 시 규칙 판정을 사용한다.
2. 팀에서 정한 탐지 전용 방식에 따라 모든 분류의 `continue_processing`은 `true`로 둔다. 이 결과로 권한을 부여하거나 채팅을 중단하지 않는다.
3. `warn` 이상이면 요청·사용자·Save·역할·캐릭터 식별자와 신호 코드를 담은 감사 이벤트를 만들되 질문 원문은 넣지 않는다.
4. 정상·공격 Mock 질문으로 규칙 검사와 모델 결합을 독립 검증한다. 채팅 전송 API가 준비되면 인증·Save 확인 이후 호출 및 H 저장·대시보드 전달을 연결한다.
