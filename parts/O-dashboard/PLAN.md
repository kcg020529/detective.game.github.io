# O01 - Grafana 보안 감사 대시보드 (선영)

1. 기존 MariaDB·Qdrant Compose를 바꾸지 않고 Grafana를 별도 Compose 파일로 선택 실행한다. 웹 주소는 로컬 `127.0.0.1:3000`으로 제한한다.
2. H의 `audit_events`를 읽는 Grafana 전용 MariaDB 계정에 `SELECT` 권한만 부여한다. 관리자·DB 비밀번호는 Git 제외 `.env`에 둔다.
3. 현재 실제로 저장 가능한 `input_guard_alert`를 대상으로 선택 기간의 경고 건수, 고위험 건수, 시간별·캐릭터별 건수와 최근 경고 메타데이터를 표시한다. `allow`는 저장하지 않으므로 전체 질문 수나 차단율로 표시하지 않는다.
4. 질문·답변 원문, 계정 식별자, Save ID, 요청 ID는 대시보드에 표시하지 않는다. 정책 거부·검색 차단·출력 마스킹은 해당 이벤트가 실제 저장된 뒤 별도 패널로 추가한다.
5. 브라우저 접속, 데이터 소스 상태, 패널 SQL을 검증한다. 실제 채팅 자동 수집은 I 채팅 전송 API와 H 호출 연결 후 별도로 확인한다.
