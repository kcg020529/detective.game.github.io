# J01 - 게임 메인 UI 및 6개 AI 캐릭터 채팅 화면 구현

1. 화면 흐름 정리
   - 시작 → 로그인 → 정문 → (새 수사) 역할 선택 → 단말기 진입 → 조사 화면
   - 각 화면에서 정문으로 돌아가는 경로와 재진입 흐름 포함
2. 공통 화면 틀 구성
   - 4:3 게임 창, 색·글꼴 기준, 픽셀 연구소 그림
   - 브라우저 크기에 맞춰 비율 유지
3. 시작·로그인·정문·역할 선택 화면 구현
   - 로그인·역할 선택은 Mock으로 처리하고 실제 인증은 J03에서 연결
   - 역할 3종(교수 `prof`·대학원생 `grad`·학부 연구생 `std`)과 역할별 열람 범위 안내
4. 단말기 진입 화면 구현
   - 관찰실 모니터 확대 → 출입증(저장 기록) 선택 → 바탕화면
5. 조사 화면(단말기 바탕화면) 구현
   - 창 열기·이동·최소화·닫기, 작업 표시줄, 시작 메뉴
6. 6개 AI 캐릭터 채팅 화면 구현
   - YB-1~6 목록과 캐릭터별 대화 기록
   - 추천 질문·자유 질문 입력
   - 답변 종류 표시: 정상 / 일부 가림 / 접근 제한 / 모름
7. 캐릭터·대화 데이터 분리
   - 임시 캐릭터 설정과 대화 예시를 화면 코드와 분리
   - 캐릭터 설정이 확정되면 교체할 수 있게 구성
8. 테스트
   - 전체 화면 흐름, 정문 복귀 후 재진입, 키보드 조작, 화면 크기별 레이아웃, 콘솔 오류 확인

# J02 - Day·조사 Token·Save·단서·최종 추리 UI 구현

1. 게임 상태 표시
   - Day, 역할, 조사 Token, 게임 내 시간 표시
2. 조사 Token 차감·소진 처리
   - 질문할 때 Token 차감, 모두 쓰면 질문 입력 막기
3. Save 슬롯 UI 구현
   - 저장 슬롯 3칸, 이어하기·새 수사, 채워진 슬롯 덮어쓰기 재확인
   - 슬롯마다 역할 고정
4. 단서 UI 구현
   - 단서 수첩, 단서 획득 알림
   - 기록 보관함에서 역할 등급보다 높은 파일은 잠금 표시
5. Day 전환 UI 구현
   - 다음 Day로 넘어가는 화면과 Token 초기화 표시
6. 최종 추리(지목) UI 구현
   - YB 지목·제출, 결과 화면
7. 서버 상태 연동 준비
   - Day·Token·Save·단서 값을 한곳에서 받도록 정리
   - 실제 API 연결은 J03에서 진행
8. 테스트
   - Token 차감·소진, Save 선택·덮어쓰기, 단서 획득, 지목 제출 흐름 확인
