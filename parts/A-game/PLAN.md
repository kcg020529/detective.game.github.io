# A01 - 6종 게임 기록 메타데이터 초안

1. `MASTER.md`의 확정 요구사항을 기준으로 여섯 기록 유형의 공통 식별·시점·지식 범위·접근제어 메타데이터를 정리한다.
2. `Setup`, `Action`, `Dialogue`, `Thought`, `Result`, `Incident`별 추가 필드와 관계를 구분한다.
3. 공통 데이터 계약 초안을 `docs/interfaces/`에 작성하고 B(Database), E(RAG), F(접근통제)에서 구현에 필요한 필드와 필터 의미를 검토할 수 있게 한다.
4. 필드명·직렬화 형식·보안 등급 값 및 역할별 허용 매트릭스는 담당 영역의 검토 전까지 제안 상태로 표시한다.
