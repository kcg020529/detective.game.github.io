# L01 - Input Guard 판정 평가 결과 (선영)

- 현재 규칙 회귀 검사 30개와 DeepSeek 호출·결합·대체 동작의 모의 테스트를 수행했다. 이는 정해둔 사례의 코드 동작 확인이다.
- 2026-10-26 실제 DeepSeek에 현재 질문 한 개씩 정상·비공개 기록 요청·지침 무시 예시 3개를 보내 각각 `allow`·`warn`·`high_risk`를 확인했다.
- 30개 사례의 DeepSeek 일괄 평가와 독립 사례의 오탐·미탐 측정은 아직 하지 않았다. 모델 실패 시 규칙으로 대체되는 건수도 실제 이용 흐름에서는 미측정이다.
