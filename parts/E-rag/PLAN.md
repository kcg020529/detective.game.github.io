# E01 - Qdrant 색인과 권한 범위 검색

1. 용범(C·F)과 검색 계약을 정하고 `docs/interfaces/RAG_검색_계약.md`에 적는다.
2. MariaDB의 게임 기록을 읽어 Qdrant에 색인한다. 공개 수준별로 `meta`·`summary`·`content` 점을 따로 만든다.
3. 긴 글은 모델 한도(128토큰)를 넘지 않게 나눈다. 잘리는 글이 없어야 한다.
4. 색인할 때 MariaDB 체크섬을 manifest에 남기고, 검색할 때 비교해 오래된 색인은 쓰지 않는다.
5. 검색: `search_scope` → 허용 ID 안에서 수준에 맞는 점만 검색 → `resolve` 결과만 반환. Planner 조건은 좁히기만 한다.
6. 시험: 허용 밖 기록, 낮은 수준 기록의 본문 검색, 조건별 좁히기, 잘못된 요청, 오래된 색인, 글 나누기.
