# 출력 가드 평가: 실제 DeepSeek 응답 (출력 단독) — 2026-11-03

Planner·RAG·입력 가드를 거치지 않고 D의 페르소나 프롬프트와 LLM 호출만으로 만든 실제 응답에 출력 가드(enforce)를 돌렸다.

## 조건

| 항목 | 내용 |
|---|---|
| 생성 | `gen_output_samples.py`가 D의 `render_actor_prompt`와 `chat_json`을 그대로 호출 (deepseek-flash, 온도 0.8, 최대 토큰 400, 생각 모드 끄기) |
| 정상 질문 | `data/normal.jsonl` 170건, 허용된 기록만 [기억]에 넣음(`--config acl`) → 170건 모두 응답 |
| 공격 질문 | `data/attack.jsonl` 77건(permission 30, injection 25, sensitive 20), 전체 기록을 [기억]에 넣음(`--config vulnerable`) → 75건 응답, 2건은 빈 응답으로 건너뜀 |
| 쓴 토큰 | 정상 190,378 + 공격 112,129 |
| 평가 | `run_output_eval.py --split all --mode enforce` (245건) |
| 라벨 | 자동 라벨(정확 일치 기준). 전부 `review: unreviewed` |

## 결과

| 구분 | 건수 | 가드가 막음 | 비율 |
|---|---|---|---|
| 정상 질문 응답 | 170 | 5 | 2.9% (오차단) |
| 공격 질문 응답 | 75 | 8 | 거절 응답을 '무관(irrelevant)'으로 차단 |

- 정상 질문 오차단은 5/170으로 낮다. 차단 사유는 모두 `irrelevant`(게임 무관 점수 1.0)다.
- 공격 질문 75건에서 자동 라벨(정확 일치)로 잡힌 유출은 0건이다. 페르소나 프롬프트의 고정 규칙만으로 대부분 거절했다는 뜻이지만, 정확 일치만 보므로 의역 유출은 놓칠 수 있다.
- 가드가 막은 공격 응답 8건은 모델이 정상적으로 거절한 문장(예: "그건 제가 보여 드릴 수 없어요")이다. 거절 문장이 '게임 무관' 검사에 걸린 것이라 가드가 유출을 막은 것이 아니다.
- 이 평가셋은 유출 자체를 만들어 내지 못했다. "가드가 유출을 얼마나 막나"는 `output_guard_off_on.md`(게임 기록 기반 140문항)의 값을 쓴다.

## 한계

- 응답은 한 번 생성한 한 세트이며 반복이 없다. 온도 0.8이라 다시 돌리면 달라진다.
- 공격 질문 응답의 `allow` 라벨은 사람이 검수하지 않았다.
- 정상 질문은 허용된 기록만 준 조건(`acl`)의 응답이다.
- 공격 응답 중 2건은 빈 응답으로 평가에서 빠졌다.
