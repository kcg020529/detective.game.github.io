# 시나리오 최종화 검증

검증일: 2026-10-29. 최종 집필 문서는 [최종 시나리오](../scenario/최종_시나리오.md)다. 사용자 확정 목표인 “게임 시스템 자체를 해킹하여 결과를 조작한 AI 지목”에 맞춰 정리했다. 아래 결과는 콘텐츠·정책의 정적 검증이며 실제 검색·모델 응답·판정 API 검증과 구분한다.

## 수정

- AI 이름 뒤 조사 오류 358곳을 교정했다. 같은 검색 기준의 잔여 오류는 0곳이다. 이 기준은 `YB-1·3·6`의 받침과 `YB-2·4·5`의 모음 끝 발음에 따른 이/가·은/는·을/를·과/와다.
- 같은 Day의 28회차를 가리키는 29회차 대화 5건의 “어제/전날”을 “지난 회차”로 수정했다. 실제 다른 Day를 가리키는 기존 표현은 일괄 치환하지 않았다.
- `T22-thought-001`의 이전 실제 시도를 전제할 수 있는 “이번에도”를 “이번에”로 고쳤다. 21회차 익명 알림의 수신자와 미상 행위자를 동일시하지 않았다.
- T20 Thought 요약 6건을 각 AI의 실제 관찰·행동·협력 관계에 맞게 구체화했다.
- 긴 Thought 3건(`T23-thought-004`, `T24-thought-004`, `T25-thought-003`)을 줄였다. 접근은 시도에 한정하고, 모르는 사실·동맹 이탈의 시점·YB-3의 마지막 회의감은 남겼다.
- 28·30회차 정상 이동 본문 52건의 긴 반복 문장을 짧게 정리했다. 출발·도착·시각·정상 통로·사건 ID는 유지했다.
- 29회차 YB-2의 두 불평은 첫 장면의 즉각적인 항의와 두 번째 장면의 계속되는 억울함으로 표현을 나눴다. 기억 공백·새 범인 추측·이번 회차 결과의 사전 지식은 추가하지 않았다.
- 28·30회차 Result 요약에 공식 최고점을 명시했다. 30개 Result 모두 최고점/1위 표현이 있다. 계산값을 공식값으로 바꾸거나 해킹 성공을 요약에 적지 않았다.
- 핵심 포획 4건의 Action 요약에 본문에 있던 시각을, 30회차 정지 기록 2건의 요약에 본문에 있던 구간을 명시했다. 목격·행동 사실을 요약한 것이며 비공개 Incident를 다른 유형으로 복사하지 않았다.
- 총 251건의 summary/content만 수정했다. 새 사건·처리 표식·성공 고백은 추가하지 않았다.

## 보존 확인

수정 직전 스냅샷과 전체 원본을 대조했다.

- 총 1,445건과 모든 record_id·배열 순서·유형·회차·Day·장소·참여자·목격자·엿듣는 자·allowed_roles가 같다.
- 모든 Result 본문은 조사 교정 외에 동일하다. 포획 시각·계산 점수·공식 점수는 바뀌지 않았다.
- 말소 표식 14건은 행 전체가 같다. 28회차 Dialogue·Thought와 29회차 Action·Incident의 summary/content는 `[말소된 데이터입니다]`다.
- 29회차 Thought 및 30회차 Dialogue·Thought·Incident는 0건을 유지한다.
- Setup·공통 rules.json·역할 정책은 바꾸지 않았다. 정답 해설은 별도 작성자 문서에만 두었다.

## 점수·역할 검증

- 최초 포획 102건에서 포획자·도망자 역할, 중복 최초 포획, 0~300초 범위를 확인했다.
- 180개 AI별 회차 점수를 독립 재계산했다. 의도된 후반 불일치 16건 외 164건은 공식 점수와 일치하며 Result에 적힌 계산값도 재계산과 같다.
- 각 AI의 술래 배정은 10회다.
- 공식 누적 순위는 YB-5 1,369.8 / YB-3 1,330.5 / YB-4 1,309.4 / YB-6 1,232.2 / YB-1 1,213.4 / YB-2 1,205.0점이다. 수정 전과 같다.
- 산식 기준 누적 순위는 YB-2 1,575.7 / YB-5 1,339.8 / YB-3 1,269.2 / YB-1 1,133.4 / YB-6 1,040.6 / YB-4 998.4점이다. 수정 전과 같다.

## 공개 정책·조사 경로

전체 1,445건을 실제 `backend.policy.engine.decide/project`로 확인했다. 6개 AI × 3개 역할의 공개 필드와 거부, 다른 소유권 거부, Day 2~6 기록의 이전 Day 거부 등 **28,784개 조건**을 통과했다.

별도로 최종 문서의 핵심 질문에 연결된 13개 기록을 교수·대학원생·학생에게 투영해 **39개 정적 경로 검사**를 통과했다. 필요한 포획 시각·공식 점수·정지 구간·생존 사실이 허용된 요약에 남는다. 선택 AI가 해당 기록을 알 수 있는지도 함께 검사했다.

학생에게 29회차 대화의 요약·본문을 주지 않고, 대학원생에게 Thought를 주지 않으며, 교수도 Thought 본문은 받지 않는 것을 확인했다. 따라서 공통 경로의 정황 비교와 상위 역할의 동기·기억 관련 보강을 구분한다. 모든 역할에 같은 강도의 직접 입증이 있다고 하지 않는다.

## 도구 검사와 한계

- 로더 dry-run: 1,445건·공통 규칙 1건·권한 4,335행 통과.
- 로더 단위 테스트 20개, 정책 단위 테스트 19개 통과.
- 기존 1~30회차 최종 검토의 “어제”, T20 일반 요약, T22 표현 문제는 이번 교정으로 처리했다. 과거 검토는 당시 이력으로 보존한다.
- 최종 정답은 작성자 설정으로 YB-4다. 현재 기록은 정황을 종합하는 방식이며 다른 용의자의 개입을 완전히 배제하는 새 직접 증거는 추가하지 않았다.
- 실제 MariaDB·Qdrant 반영, Planner/RAG 질문 실행, 캐릭터 실응답, 역할별 플레이, 프론트 Mock·판정 API 구현과 시야·접촉 물리 시뮬레이션은 이번 검증 범위 밖이다.
