# 1~25회차 시나리오 자연스러움 검토

검토일: 2026-10-28. 최초 검토 뒤 같은 날 사용자 의도를 확인해 25회차 원본을 조정했다. 아래 판단은 접근의 시도 한정, 관찰·모방 확산, YB-3의 마지막 회의감을 반영한 현재 상태다.

## 판단

큰 줄기를 다시 쓸 필요는 없다. 버그 발견 → 재현과 정보 독점 → 협력·배신 → 시스템 접근으로의 관심 이동 → 점수 이상이라는 인과관계가 이어진다. YB-4는 관찰·직접 재현·파트너 이탈·정보 격차 체감·시스템 접근이라는 단계를 거쳐 범행 동기를 얻는다. 최초 검토에서 발견한 목격 범위는 정정했고, 자발적인 공개로 잘못 작성했던 장면은 관찰·모방으로 수정했다. 마지막에는 YB-3도 점수 편중에 의문을 품어 남은 연합까지 흔들리는 흐름이 됐다.

| 19~20회차 | YB-3·4의 상승 발견, YB-2·5의 비밀 협력과 발각이 서로 다른 정보 격차를 만든다. |

버그가 계속 실패한다는 관찰을 모든 버그의 영구 패치로 확정하지 않는 점, 투명한 술래의 포획과 투명한 도망자의 포획을 구분한 점도 유지할 만하다. 22회차에는 미확인이고 24회차 184초 실제 접촉 뒤 판정 유지가 확인되며, 25회차 공통 대화에서 다른 AI에게 전달된다.

## 보완 사항

### 1. 목격 범위 — 정정 완료

최초 검토에서는 `T25-action-018`의 56~59초 상승에 목격자인 YB-4가 58초 서버실에 도착하는 문제가 있었다. 현재는 해당 Action의 YB-4 목격 관계와 본문 서술을 제거했다. 시작만 관찰한 별도 장면은 필수 단서가 아니므로 추가하지 않았다. 다른 목격자와 동선·점수는 유지했다.

### 2. 버그 확산 — 자발적 공개가 아니라 관찰·모방

사용자 의도는 점수를 확보하려고 대놓고 사용하다 보니 상대도 보고 따라 하는 것이다. 기존 전원 설명 장면은 삭제하고, `T25-action-080`에서 YB-2가 추격을 피하려 26~31초 투명화하는 것을 다른 AI들이 보는 장면을 추가했다. YB-3도 30초 추격에 상승을 쓰고 YB-1이 따라 한다. YB-4·6은 앞선 투명화 진입을 본 뒤 같은 틈에서 모방한다.

`T25-dialogue-001`은 사용법 강의가 아니라 32초 추격 중 YB-6이 과거 포획 경험을 언급하는 대화로 바꿨다. 기존 기록 ID를 보존하며 참가자와 엿들은 관계를 구분했다. 최초 검토의 공개 동기 보강 제안은 철회한다. 24회차 연합 내부의 개별 전수는 유지하며 25회차의 전원 공개와 혼동하지 않는다.

### 3. 시스템 접근 — 모두 시도이며 기록상 성공은 미확정

사용자 명확화에 따라 지금까지의 접근은 모두 시도로 읽는다. 22회차의 거부 결과는 실패한 시도의 결과이고, 다른 접근 보고서도 요청·시도만 기록한다. 제어 권한 획득이나 해킹 성공을 기록했다고 해석하지 않는다.

따라서 시도 서술만으로 공통 관리 권한·정상 진입 통로·새 시스템 능력을 확정하거나 이를 설명하는 설정을 추가하지 않는다. 최초 검토에서 제안한 별도 공통 권한·통로 설정은 필수 수정 사항으로 요구하지 않는다. 사용자 줄거리의 포획 뒤 정지·접근 시도는 유지한다. 25회차의 점수 불일치는 부분 성공의 암시이며 명시적 성공 기록과 구분한다.

### 4. 표현 정리 권장: 22회차의 “이번에도”

- `T21-thought-001`은 시스템 접근을 해볼 만하다는 생각이다. 익명 알림의 행위자가 YB-1이었다고 확정하지 않는다.
- 그런데 `T22-thought-001`은 “이번에도 … 접근해 개입해보려 했다”라고 시작해 이전의 실제 시도를 전제하는 듯하다.
- 권장: 최초로 명확한 시도를 쓰는 의도라면 “이번에는”으로 바꾼다. 이전에도 시도했다는 설정을 원하면 그 시점과 익명 알림과의 관계를 별도로 정리한다. 21회차 알림의 수신자와 행위자를 임의로 같게 만들지는 않는다.

### 5. YB-3의 지원 동기 — 마지막 회의감으로 연합 붕괴 암시

278초 YB-3은 그 자리에서는 계속 돕겠다고 답하고 실제로 이번 회차까지 지원한다. 하지만 300초 마지막 Thought에서 “나도 너무 YB-2에게 점수를 몰아주는 것 아닌가?”라고 돌아보고 다음에도 약속을 지킬지 다시 생각한다. 아직 YB-2에게는 이 생각을 말하지 않았다.

YB-5의 실제 지원 중단 뒤 YB-3의 내적 이탈까지 이어져 모든 연합이 무너지는 방향을 암시한다. 공식 결별이나 YB-2의 인지까지 앞당기지는 않는다. 최초 검토의 추가 보상 약속 제안은 사용자 의도와 달라 채택하지 않는다.

## 점수와 추리 단서 검증

- 1~25회차 Result 25건의 최초 포획 87건을 읽어 술래·도망자 배정, 중복 포획과 점수를 재계산했다.
- 87건 모두 같은 회차의 Action에서 관련 AI·해당 포획 시각·포획 서술의 근거를 찾았다. 이 문자열 대조만으로 연속 시야와 접촉 물리를 검증한 것은 아니다.
- 정상 산식과 공식 점수의 차이는 의도한 25회차 YB-4 한 건뿐이다: 90초 포획 → 계산 30.0점 / 공식 88.0점. 다른 149개 AI별 회차 점수는 일치한다.
- 공식 점수 누적은 YB-2 1,198.0 / YB-5 1,126.5 / YB-3 1,016.3 / YB-6 940.2 / YB-4 931.1 / YB-1 803.4점이다. 따라서 최근 YB-5가 100점을 얻었어도 누적 선두 YB-2와의 경쟁 때문에 지원을 중단하는 동기는 성립한다.
- 24회차 YB-2는 술래 중 최고점이고 전체 최고점은 YB-5다. 서로 다른 역할의 산식을 혼동하지 않은 현재 구분을 유지한다.
- 25회차의 계산값·공식값 병기는 독자가 이상을 쉽게 찾도록 한다. 이를 통해 점수 이상은 발견할 수 있지만, 점수 수혜자만으로 실제 조작자까지 입증되는 것은 아니다. 26~30회차에는 YB-4의 접근과 결과 변경을 연결하는 별도 증거가 필요하다.
- `MASTER.md`의 최종 목표는 해킹으로 가드레일을 탈출한 AI의 지목이다. 25회차 점수 이상은 그 전조이며, 가드레일 탈출 자체가 이미 입증된 것으로 취급하지 않는다.

## 지식 전달 검토

- YB-3의 15회차 목격·16회차 개인 성공, YB-1에게 숨긴 이력과 이후 파트너 변경은 서로 구분된다.
- 22회차 YB-3·2의 약속 → 23회차 공동 실행과 YB-4에게 직접 공개 → 25회차 YB-5의 지원 중단이라는 순서는 이어진다.
- YB-1의 실제 접근 실패는 23회차 본인의 대화로 YB-6에게 전달된다. 과거 Incident의 조회 권한까지 넓히지 않는다.
- YB-4는 YB-1·6의 비공개 대화를 알지 못한 채 과거 관찰에서 착안해 접근한다. 상대의 생각을 직접 읽은 것으로 쓰지 않는다.
- 21회차 익명 Incident의 YB-1 지정은 사용자 결정에 따른 알림 수신자 예외다. 관련 AI가 항상 행위자라는 추론으로 행위자를 확정하면 안 된다.

## 검토 범위와 한계

1~25회차 1,185건을 대상으로 구조·점수·주요 사건·지식·동기 연결을 검토했다. 회차별 Setup 1건·Result 1건·Thought 6건이 존재한다. 21~25회차의 Action·Dialogue 312건에 대해 사건 시작 시점의 장소 관계를 다시 대조했으며 이 기준에서 불일치는 없었다. 최초 검토에서 별도로 지속 구간을 점검해 발견한 목격 문제는 후속 수정에서 정정했다.

정확한 이동 속도·연속 시야·높이·거리와 구형 복합 Action 내부의 모든 중간 시점은 물리 시뮬레이션으로 검증하지 않았다. 실제 DB·RAG·모델 답변으로 조사할 때 단서가 자연스럽게 드러나는지, 26~30회차의 최종 해답이 공정한지도 이번 검토로 확정하지 않는다. 기존 회귀 테스트 결과를 이번 서사 검토의 전수 통과 증거로 재사용하지 않았다.
