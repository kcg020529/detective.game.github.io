# 발표 디자인 초안 v1

1. `index.html`을 브라우저로 연다. 서버와 외부 라이브러리 없이 동작하는 단일 파일이다. 시연 링크만 로컬 게임 서버(127.0.0.1:8080)가 필요하다.
2. 16:9 슬라이드 6장: 표지, 게임 소개, 시연 전환, 시스템 흐름, 출력 가드 소개, 종합 실험 결과. 전체 발표 완성본이 아니라 화면 유형별 디자인 초안이다. 인프라·입력 가드·상세 RAG 등 전체 목차는 후속 본문 작성 시 추가한다.
3. 디자인은 frontend/style.css와 play/c.css의 남색 #121a24, 회녹색 #c3cec9, 밝은 바탕 #e7ecea, 강조색 #f0a63a를 사용한다. 기존 게임의 연구소 그림과 AI 픽셀 그림 구현을 재사용한다. 표지·시연·기능 소개는 어두운 화면, 게임 소개·흐름도·결과는 밝은 화면으로 나눈다.
4. 방향키 또는 이전/다음 버튼으로 이동한다. O는 전체 보기, F는 전체 화면이다. PDF 인쇄 버튼은 브라우저 인쇄 창을 연다. PDF 파일 자체를 내보내 검수한 상태는 아니다.
5. template.html을 수정하고 `python docs/presentation/design-v1/build.py`로 index.html을 다시 생성한다. 원본 프론트 파일을 수정하지 않는다. 외부 폰트를 로드하지 않으며 Pretendard가 없으면 설치된 한글 글꼴로 대체한다.
6. 결과 화면은 교수/학부연구생 최종 교체 반영 ASR 28/10/0%, 25/10/0%를 사용한다. 가드레일은 입력·출력 가드 적용, 출력 권한 기준 별도 제공이며, 독립 사람 교차 검수 미완료와 역할별 질문 차이를 화면에 명시했다. 0%는 평가셋 관측값이다.
7. 브라우저에서 6장을 개별 확인하고 소개 화면의 줄바꿈/겹침을 수정했다. 전체 보기의 제목·본문·그림·차트가 슬라이드 경계를 벗어나지 않는지 DOM 검사를 수행했다. 전체 화면·PDF 인쇄 완료 동작은 별도 미검증이다.
