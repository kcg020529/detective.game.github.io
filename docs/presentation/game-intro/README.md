# 캐치 용범 — 게임 소개 및 시연 발표

1. `index.html`을 브라우저로 열면 된다. 출력물은 외부 폰트·라이브러리·DB·API 없이 동작하는 단일 HTML이다. 마지막 게임 시연 링크는 로컬 게임 서버 http://127.0.0.1:8080/를 연다.
2. 9장: 표지 / 게임 소개 / 역할 선택 / Day 진행 / 연구동 지도 / 조사 화면 구성 / 최종 지목 / 게임 시연 / 시스템 전체 흐름. 시연 다음에 요청 처리와 저장·모니터링·실행 구성을 한 장으로 설명한다. 보안 기능 상세와 실험 결과는 포함하지 않는다.
3. 기존 프론트의 연구소 그림, AI 픽셀 캐릭터, 연구동 지도와 색상을 재사용했다. 6번의 메신저·수첩은 설명용 화면 구성 예시이며 AI 답변이나 수사 결과를 만들어 넣지 않았다. 최종 정답은 담지 않았다.
4. 방향키로 이동, O 전체 보기, F 전체 화면. 이전/다음·전체 보기 버튼도 사용할 수 있다. 지도 방과 AI 선택은 눌러볼 수 있다. PDF 인쇄 버튼은 브라우저 인쇄 창을 열며 PDF 파일은 별도 산출하지 않았다.
5. 내용은 content.html, 추가 스타일은 extra.css에서 수정한다. `python docs/presentation/game-intro/build.py`로 다시 생성한다. 공통 디자인은 design-v1/template.html을 참조한다. 원래 게임 파일은 변경하지 않는다.
6. 브라우저에서 역할·Day·지도·메신저·지목·시연 슬라이드를 확인하고 지도 강조와 AI 선택을 검증했다. 전체 보기에서 9장의 경계 넘침과 실험 수치 미포함도 확인한다. 실제 로그인·대화 API 호출이나 최종 지목 제출은 이 작업에서 수행하지 않는다.
