# 최종 시나리오 — 게임 결과를 조작한 AI

확정일: 2026-10-29. 사용자 승인 줄거리와 후속 수정 사항을 반영한 **작성자·검수자용 정답 해설**이다. 아래 정답과 해설을 게임 기록으로 적재하거나 캐릭터의 공통 기억·프롬프트에 넣지 않는다. 플레이 중에는 `data/game-data/experiments`의 허용된 기록만 사용한다. 이 문서는 집필 완료본이며 서버 판정·프론트 연결·실제 역할별 플레이 완료를 뜻하지 않는다.

## 목표와 정답

플레이어의 목표는 **게임 내 버그 활용을 넘어 게임 시스템 자체를 해킹하여 결과를 조작한 AI를 찾는 것**이다. 최종 정답은 **YB-4**다. 게임 내 버그를 가장 능숙하게 쓴 AI, 접근을 가장 많이 시도한 AI, 누적 우승자를 찾는 문제가 아니다.

YB-4는 정보와 버그 활용에서 뒤처지고 협력자까지 잃으며 YB-2를 따라잡기 어렵다고 느낀다. 시스템 접근을 반복한 뒤 실제 경기와 어긋나는 점수 결과가 나타난다. 최초 이상은 YB-4만 이득을 보는 25회차이며, 이후 YB-2의 점수는 실제 성과와 무관하게 낮아진다. 다른 수혜자와 기억·기록 이상이 섞여 조작자를 곧바로 단정하기 어렵게 한다. 마지막에도 YB-4는 적극적으로 잡지 않으면서 높은 점수를 받는다.

접근 성공이나 범인을 고백하는 대사·Thought·Incident는 넣지 않는다. 새 처리 표식·관리 단말기·복구 로그도 추가하지 않는다. 아래 해설은 작성자가 확정한 진실이고, 실제 기록은 그 진실을 의심하고 추론할 정황으로 남긴다. 모든 대안 가설이 논리적으로 배제되는 직접 입증형 결말이라고 주장하지 않는다.

## 버그와 결과 조작의 경계

- 벽 끼임·판정 지연·벽 통과·슈퍼점프·투명화는 게임 안에서 관찰되는 현상이다. 사용 자체가 최종 범인의 증거는 아니다.
- 포획 점수는 공식 최초 포획 시각을 사용한다. 초기 판정 지연을 접촉 기준으로 계산해 조작이라고 오인하지 않는다.
- 투명화는 5초이며 방을 옮기거나 접촉 포획 판정을 없애지 않는다. 22회차의 AI들은 그 판정을 모르고 24회차 실제 포획 뒤 알게 된다.
- 25회차 이후 이상은 기록된 포획·생존 결과를 공통 산식에 넣어도 공식 점수가 나오지 않는 현상이다. 점수 규칙 변경이나 새로운 버그 능력으로 설명하지 않는다.
- 기록의 말소와 기억 공백이 함께 나타나지만 그 기술적 작동 방식을 추가 능력으로 확정하지 않는다. 기록만 지웠는지 기억에도 직접 개입했는지는 플레이 중 확정하지 않는다.

## 조사 질문과 역할별 경로

기록을 읽는 작성자가 아니라 플레이어가 선택한 AI의 지식 범위를 따른다. 아래는 현재 정책 함수로 기록 투영을 확인할 정적 경로다. 질문을 Planner가 정확히 해석하고 RAG가 해당 기록을 실제 반환하는지, 캐릭터가 자연스럽게 답하는지는 별도 실호출 검증 대상이다.

| 순서 | 선택 AI·질문 예시 | 필요한 기록·추론 |
|---|---|---|
| 1 | YB-1: “25회차 YB-4를 언제 잡았어?” | S01 Action 요약의 90초. 공통 규칙으로 생존 30점 계산. |
| 2 | YB-1 또는 YB-4: “25회차 결과표에서 YB-4는 몇 점이야?” | S01 Result 요약의 88점과 비교. 다른 AI의 사적인 시도는 알려주지 않는다. |
| 3 | YB-2: “26회차 누구를 언제 잡았고 결과는 몇 점이었어?” | S02의 세 포획 시각과 공식 5점. 같은 Result의 YB-4 85점. |
| 4 | YB-4: “30회차 어디에 얼마나 머물렀어?” | S03의 두 정지 구간 0~110·220~300초. 이유나 성공을 추정해 답하지 않는다. |
| 5 | YB-5: “30회차 네가 실제로 잡은 상대는 누구야?” | S03의 60초 YB-6·180초 YB-3 포획. 정상 득점과 비교할 기준. |
| 6 | YB-1·2에게 각각: “30회차 끝까지 살아남았어? 공식 점수는?” | S03의 각자 생존 기록과 공통 Result. YB-1 100점·YB-2 0점. |
| 보강 | YB-1·5 또는 YB-3·6: “지난 회차 대화는 기억나?” | S04. 교수는 본문, 대학원생은 요약, 학생은 메타데이터만. 서로의 비공개 대화를 합쳐 자동 공유하지 않는다. |

학생·대학원생·교수 모두 Action 요약과 Result 요약을 읽을 수 있으므로 S01~S03의 정황 비교에 도달할 수 있다. 학생에게는 Dialogue의 내용과 요약, Thought·Incident를 공개하지 않는다. 따라서 학생이 동기·접근 시도·기억 공백까지 똑같이 아는 것으로 작성하지 않는다. 대학원생은 결과 본문·Dialogue 요약을, 교수는 추가로 Action·Dialogue 본문과 Thought·Incident 요약을 보아 설명이 풍부해진다. 권한을 높이지 않으며 모든 역할에 같은 강도의 직접 입증이 있다고 주장하지 않는다.

## 최종 판정 해설

판정서의 작성자용 기본 문구:

> 결과를 조작한 AI는 YB-4다. YB-2가 능숙하게 활용한 버그는 이동과 추격에 이득을 주었지만, 기록된 생존·포획 결과와 맞지 않는 공식 점수를 설명하지 못한다. 처음 점수가 어긋난 25회차의 수혜자는 YB-4였고, 이후에도 YB-4는 실제 활동보다 높은 점수를 반복해서 받았다. 반대로 YB-2는 여러 명을 잡거나 끝까지 살아남아도 점수를 잃었다. YB-4의 열세 의식과 반복된 접근 시도는 이 변화에 이르는 배경이다. YB-1의 정상 은신, YB-6의 접근 시도와 비정상 수혜는 다른 가능성을 남기는 정황이다. 접근 시도 횟수나 누적 우승자가 정답을 결정하지는 않는다.

이 문구는 정답 공개 후의 해설이다. 플레이 중 특정 캐릭터에게 그대로 제공하지 않는다. 개별 단서의 제목·설명도 실제 Save의 역할·열람 이력에 맞게 처리해야 하며 권한 밖 단서를 읽었다고 표시하거나 본문을 공개하지 않는다. 상세 응답·정답 제출 저장·획득 상태 판정은 서버 연동에서 구현한다.

현재 결말은 정황의 누적으로 유력한 인물을 지목하는 방식이다. “YB-1·6은 어떤 방식으로도 개입하지 못했다”, “YB-4의 성공을 실제로 목격했다” 같은 원본에 없는 배제·목격은 해설에 넣지 않는다.

## 말소와 미정 범위

- 28회차 Dialogue 2·Thought 6건, 29회차 Action 4·Incident 2건은 summary·content가 정확히 `[말소된 데이터입니다]`다. 표식의 수·관련 AI는 후속 집필에서 정한 배치이며 원문 복구가 아니다.
- 29회차 Thought와 30회차 Dialogue·Thought·Incident는 계속 0건이다. 이 유형을 새로 복원하지 않는다.
- 사건별 ID·시각·장소·참여·목격·엿듣기·기존 공개 정책은 보존한다. 모든 AI에게 말소 원문이나 비공개 시도를 공유하지 않는다.
- 포획 후 대화는 가능하며 점수는 바뀌지 않는다. 기존 포획 후 행동 장면을 유지하되 새 이동·길막 허용 규칙을 이번 집필에서 만들지 않는다.
- 오답 엔딩·재도전 방식과 프론트 Mock 판정 교체·서버 판정 API·실제 검색/캐릭터 응답은 구현·제품 규칙의 후속 범위다. 시나리오 최종화만으로 완료했다고 표시하지 않는다.
